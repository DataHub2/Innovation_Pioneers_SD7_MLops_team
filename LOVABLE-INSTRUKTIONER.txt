 4. KODEN SOM SKA IN
--------------------------------------------------------------------------------

Klistra in detta i Lovable-chatten om du vill att den gör ändringen åt dig.
Texten mellan linjerna är själva instruktionen:

--------------------------------------------------------------------------------
Find the server function that loads the catalog data (the one used by
queryKey: ['catalog']). It currently returns a hardcoded demo object with the
keys household, panels, inverters, batteries, suppliers, listings,
configurations, installedSystem.

Replace its body so it fetches the data from a URL instead, but keep the
existing demo object in the file and return it if anything goes wrong, so the
page can never break:

const CATALOG_URL =
  'https://raw.githubusercontent.com/DataHub2/Innovation_Pioneers_SD7_MLops_team/main/web/catalog.json'

// The payload must have these or the app throws on .find() / .household.
// Checked rather than trusted: a 200 response with the wrong shape is the
// failure mode that a try/catch alone does not catch.
function isUsable(d: unknown): boolean {
  const c = d as Record<string, any> | null
  return !!c
    && !!c.household
    && Array.isArray(c.panels) && c.panels.length > 0
    && Array.isArray(c.inverters) && c.inverters.length > 0
    && Array.isArray(c.batteries) && c.batteries.length > 0
    && Array.isArray(c.configurations) && c.configurations.length > 0
    && !!c.installedSystem
}

export const fetchCatalog = createServerFn({ method: 'GET' }).handler(async () => {
  try {
    // ?v= busts GitHub's ~5 minute CDN cache so refreshes are immediate.
    const res = await fetch(`${CATALOG_URL}?v=${Date.now()}`, { cache: 'no-store' })
    if (!res.ok) throw new Error(`catalog HTTP ${res.status}`)
    const data = await res.json()
    if (!isUsable(data)) throw new Error('catalog shape not usable')
    return data
  } catch (error) {
    console.error('[catalog] live fetch failed, using demo data:', error)
    return DEMO_CATALOG   // <- the object literal you are replacing; keep it
  }
})

Keep the query key ['catalog'] and its staleTime. Do not rename anything.

--------------------------------------------------------------------------------
 7. RÖR INTE DESSA SAKER
--------------------------------------------------------------------------------

Två saker i vår payload ser ut som misstag. De är avsiktliga.

  * Fältet heter  bms_family  — på BÅDE batteriet och invertern.
    Din kontroll är:  battery.bms_family === inverter.bms_family
    En tidigare version av vår builder skrev battery_comm_family istället.
    Då blir båda sidor undefined, och undefined === undefined är true — så
    kontrollen GODKÄNDES av fel anledning istället för att underkännas.
    Byt inte namn på detta fält. Vår kontrolltest fäller bygget om det
    återkommer.

  * Extra nycklar:  built_utc, source, counts.
    Appen ignorerar dem helt (verifierat mot samtliga 31 chunks i din bundle).
    De finns för att göra en gammal fil uppenbar vid felsökning, och vår egen
    web/index.html läser built_utc och source för sin "Built ..."-rad.

 8. VAD SOM FORTFARANDE SAKNAS – INTE DITT PROBLEM
--------------------------------------------------------------------------------

Priser och lager. Tabellerna suppliers och listings är tomma, så:

  * "Budget"-kontrollen visar "Needs changing"
  * "Stock"-kontrollen visar "Needs changing"
  * totalsumman visas inte
  * steg 4 "My Checklist" genererar ingen inköpslista

Detta är RÄTT och INTE en bugg i din kod. Vi har inga filippinska priser än,
och att gissa en summa skulle göra budgetkontrollen till en lögn. Det fylls i
utan att du rör något: vi lägger in rader, kör om bygget och pushar.

Monitoring-grafen är fortfarande syntetisk. De 2 016 mätvärdena simulerades
för det gamla demosystemet (4,4 kW). Vårt C2 är 5,5 kW (10 x 550 W). Sidan
kommer alltså att visa 5,5 kW i rubriken medan kurvan visar det gamla
systemet. Synligt, milt inkonsekvent, ofarligt.

Sidfoten säger "All products, suppliers, prices and readings are fictional."
Panelerna och invertrarna är nu riktiga publicerade specifikationer. Vill du
kan den meningen mjukas upp till att bara priser och mätvärden är syntetiska.
Helt valfritt.
