## Task 1: check whether the compatibility checks actually work

On the build page, the card "Do these parts fit together?" runs a list of
checks and shows "Looks OK in this demo" or "Needs changing" for each.

I set the panel count to 14 with the JA Solar JAM72D30-550/MB panel and the
Deye SUN-6K-SG04LP1-EU inverter. Fourteen panels in series is about 699 V, which
is above that inverter's 500 V DC limit. Every check still said "Looks OK".

Tell me whether that is correct behaviour or a bug. If it is a bug, fix it
before doing anything else, and explain what was wrong.

Do not change anything else while you look at this.

## Task 2: add a table that shows which combinations fit together

The page can currently only confirm one combination at a time, so a user cannot
see which parts work with which. Add a section that answers it directly.

Where: on the build page, directly below the "Do these parts fit together?"
card. Put it behind a collapsed toggle labelled "Show all combinations", so it
does not overwhelm someone who has never seen a solar panel. Collapsed by
default.

What: one table.

- Rows are the panels, but GROUPED BY WATTAGE rather than one row per model.
  Group together every panel whose valid panel-count range is identical, and
  label the row with the wattage and how many models it covers, for example
  "740 W (43 models)". There are 61 panels in the catalogue; 61 rows is not
  readable.
- Columns are the inverters, one each, using their short names.
- Each cell shows the range of panel counts for which that panel works with
  that inverter, for example "4-8". If no count works, show a dash and put the
  reason in a tooltip.
- Sweep panel counts from 1 to 30.

Below that table, add a single row for the battery: for each inverter, the
maximum number of batteries that can be connected in parallel.

Under the table, one short sentence naming what limits the narrowest range and
what limits the widest, in plain words. Do not show internal rule keys or
voltage values in the table itself.

Keep the reading level the same as the rest of the page. This is for someone who
